# Cartothèque

Application d'apprentissage ludique, installable sur téléphone : leçons sous forme de cartes, quêtes du jour, série de jours, boosters à collectionner et mini-jeux (roue du jour, Défi minute, Duel tactique, Tournée de picking).

**Ouvrir l'appli :** https://lucaspruvost02.github.io/cartotheque/

## Installer sur le téléphone

- **iPhone** : ouvrir le lien dans Safari → bouton Partager → « Sur l'écran d'accueil ».
- **Android** : ouvrir le lien dans Chrome → menu ⋮ → « Installer l'application ».

L'appli fonctionne ensuite hors connexion et se met à jour toute seule quand une nouvelle version est publiée ici.

## Progression

La progression est enregistrée sur le téléphone. Pour la transférer depuis une autre version : Profil → Transférer ma progression → copier le code, puis le coller dans l'autre version.

## Fichiers

Ce dépôt contient la version construite de l'appli (`index.html`, `app.js`, `data.js`, `sw.js`, `manifest.webmanifest`, `icons/`). Les sources et le script de construction (`build_pwa.py`) sont dans le dossier `apprendre/` du dépôt privé `maillot`.
